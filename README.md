# React Windows 10 Portfolio OS
A premium, fully interactive Windows 10 inspired portfolio built with Next.js, Tailwind CSS, and Framer Motion. 

## Features
 🪟 Draggable and resizable windows
 🎨 Real-time desktop wallpaper personalization
 💻 Interactive Terminal
 📱 Fully responsive

## How to Use
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Edit `srcapppage.tsx` to add your own details!
